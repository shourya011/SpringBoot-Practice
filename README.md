# Spring Boot Learning Journey

This repository contains my code, practice exercises, and examples as I learn **Spring Boot** and Java backend development.

I'm using this repository to practice concepts, understand how Spring Boot works, and keep track of my progress through hands-on coding.

## Topics Covered

- Spring Boot fundamentals
- Creating REST APIs
- Controllers and request mappings
- Dependency Injection and Inversion of Control
- Service and Repository layers
- Working with databases
- Spring Data JPA and Hibernate
- Exception Handling and Validation
- Building backend applications

*Topics will be added as I progress.*

## Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Build Tool:** Maven
- **Database:** MySQL
- **Tools:** IntelliJ IDEA / VS Code, Git, GitHub
- **API Testing:** Postman
